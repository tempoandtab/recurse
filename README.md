# Recurse

A recursive box-pushing puzzle game in a single HTML file. Push boxes, walk into hollow boxes to enter their inner worlds, and push boxes across boundaries between worlds. Get every gold door covered.

**True recursion:** ∞ boxes contain the very room you're standing in — walk through the gold door to descend forever, bump the box's back to climb out. Only boxes in the outer world count toward goals.

## Play

- **Move:** arrow keys / WASD, or swipe on touch screens
- **Undo:** U or Z · **Reset level:** R · **Level select:** top bar
- Progress saves in your browser automatically.

## Run it

No build step, no dependencies — open `index.html` in any browser, or serve this folder with any static server. Hosted with GitHub Pages.

20 hand-designed levels in a progressive campaign (1→30 move solutions), each verified solvable by an automated solver. Levels 9–11 teach the ∞ boxes; level 20 is the finale.
